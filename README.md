# Niato AI Chat

Application de chat IA légère et moderne : multi-modèles, authentification, historique et artifacts interactifs.

- Fonctionnalités clés : chat streaming, sauvegarde de conversations, auth (email/Google/GitHub), upload fichiers.
- Stack : Next.js, TypeScript, Tailwind, Prisma, PostgreSQL.

Installation rapide :

1. Copier et remplir `.env` (voir example si présent)
2. Installer : `pnpm install`
3. Générer Prisma : `pnpm prisma generate`
4. Lancer : `pnpm dev`

Tests : `pnpm test`

Déploiement : Vercel recommandé — configurez les variables d'environnement.

Contribuer : fork → branche → PR.
